Integración con Google Maps

💡 ¿Cómo funciona Google Maps Gratis?
Google Cloud ofrece a cada cuenta $200 USD mensuales de crédito gratuito de por vida (~28,500 cargas de mapa al mes gratis). Para proyectos universitarios y demostraciones, el costo real es $0.00. Además, puedes usar el Modo Directo sin necesidad de tarjetas de crédito.
Guía rápida paso a paso para obtener tu clave gratis:
  1. Ingresa a Google Cloud Console.
  2. Crea un nuevo proyecto (ejemplo: Qgo Delivery).
  3. En el menú lateral ve a APIs y Servicios > Biblioteca.
  4. Busca Maps JavaScript API y presiona el botón Habilitar.
  5. Ve a Credenciales > Crear credenciales > Clave de API.
  6. Copia tu clave (empieza con AIzaSy...) y pégala arriba.
